# Fish a Weevil

A Roblox fishing and progression game. Luau source lives here and syncs into Roblox Studio with [Rojo](https://rojo.space). GitHub is the source of truth: don't make important scripts directly in Studio.

## Setup

1. Install [Rokit](https://github.com/rojo-rbx/rokit), then run `rokit install` in this folder.
2. Install the Rojo plugin in Studio.
3. Run `rojo serve` here and click **Connect** in the Studio plugin.
